- reset 使用 `query.delete(synchronize_session=False)` 一条 SQL 清行,而非逐行 `session.delete`:重建可能涉及大量行,批量删除更合适;生产 MySQL 的自引用外键 `ON DELETE SET NULL` 自行处理指针。
- store 分批删除中途失败时只能保证「MySQL 未删」,已删的部分向量不会回滚;这是外部向量库无事务的已知限制,记录为 concern,未在本任务扩权实现补偿。
